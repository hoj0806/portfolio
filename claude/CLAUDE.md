# 포트폴리오 사이트

프론트엔드 신입 개발자 포트폴리오. 채용 담당자가 5분 안에 읽는 문서다.

## 이 저장소의 규칙

1. 콘텐츠(문제/해결/결과 본문)는 내가 직접 쓴다. 임의로 생성하거나 채우지 않는다.
   `content/` 아래 데이터 파일에 placeholder만 만들어 두고 비워 둔다.
2. 다이어그램(SVG)도 내가 직접 만든다. 자리만 잡아 둔다.
3. 컴포넌트는 역할별로 분리한다. 한 파일이 150줄을 넘으면 나눈다.
4. `any` 금지.
5. 작업 후 `npm run build`와 `npx tsc --noEmit`이 통과해야 한다.
