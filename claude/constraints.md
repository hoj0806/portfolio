# 제약

## 성능 — 이 사이트 자체가 증거물이다

포트폴리오 본문에서 이미지 최적화와 LCP를 다룬다.
사이트가 무거우면 그 내용이 무너진다.

- Lighthouse 4개 지표 90 이상
- 다이어그램은 SVG. PNG로 내보내지 않는다
- 스크린샷은 WebP, sizes 지정, next/image 사용
- 첫 화면 밖 이미지만 지연 로딩. Hero는 제외한다
- 폰트는 서브셋 + 첫 화면 subset preload
- FOUT은 막지 않는다. 폴백을 메트릭으로 맞춰(size-adjust) 레이아웃 이동만 없애고,
  글꼴이 늦게 도착해 교체되는 것은 허용한다. `font-display: swap`.
  FOUT을 완전히 막으려면 `optional`을 써야 하는데, 그러면 첫 방문이
  폴백으로 끝난다. 처음 오는 사람이 기준이므로 그 대가가 더 크다

## 접근성

- 시맨틱 태그: article, figure, section, nav
- 헤딩 계층을 건너뛰지 않는다
- 모든 이미지에 alt, 다이어그램에 figcaption
- 키보드로 전체 탐색 가능
- 명도 대비 4.5:1 이상

## 인쇄

인쇄 시 네비게이션·토글을 숨기고 본문만 남긴다.
케이스 카드가 페이지 중간에서 잘리지 않게 한다.

## 금지

- localStorage 외의 저장소 사용 금지 (테마 저장에만 사용)
- 외부 분석 스크립트 금지
- 콘텐츠 문장을 임의로 생성하지 않는다
